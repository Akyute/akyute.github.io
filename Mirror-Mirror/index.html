Mirror Mirror is an interactive installation projecting a time-distortion generative visual for the users to interact in which an intangible reflection is created in real-time 



( ES )

Mirror Mirror es una instalación interactiva que proyecta una imagen generativa con una distorsiona del tiempo para que los usuarios interactúen, creando un reflejo intangible en tiempo real.
